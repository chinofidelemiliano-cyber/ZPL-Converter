Una imagen, muchas etiquetas

El ancho y largo de arriba corresponden a cada pieza. La imagen completa se reparte entre todas las etiquetas.

Orden de impresión: izquierda a derecha y luego la siguiente fila. Las guías verdes y los números solo aparecen en pantalla. Une las piezas sin dejar huecos para reconstruir la imagen. El gap del rollo no elimina franjas de la imagen.

La cantidad indica copias por pieza: primero se imprimen todas las copias de la pieza 1, después las de la pieza 2, etc.

Añade elementos, selecciónalos en la lista y ajusta su posición en milímetros.

Editar elemento

Usa 1 para avanzar o -1 para descender.

Prefijos y sufijos Code 39: usa mayúsculas A–Z, números o - . $ / + %. La vista previa muestra el primer número. La descarga contiene todos los números en orden, con comandos nativos. Las copias se indican en Cantidad de etiquetas.

Posición y comandos avanzados
El archivo debe existir en la impresora. GS y las fuentes adicionales dependen de tu modelo y de las fuentes instaladas.
Comandos de este elemento


Los elementos fuera del tamaño de la etiqueta se recortan. El código de barras usa Code 39; conserva sus márgenes y comprueba su lectura antes de usarlo.

Tipos de fuentes
Catálogo residente estándar: 0 y A–H. GS y otras fuentes se seleccionan por archivo instalado con ^A@. No todas las impresoras incluyen las mismas fuentes. Las muestras usan tipografías del navegador como aproximación. Se exportan como fuentes ZPL nativas (^A). Las muestras son aproximadas; el aspecto y los caracteres disponibles dependen de las fuentes de tu impresora.
